
# Day 8 Reflection

The most difficult concept I encountered during this course was understanding how the frontend, backend API and database communicate and work together. At first, I found it challenging to understand how information moves between these different parts of an application. I overcame this by practising with the assignments, revisiting the lessons and working through examples involving APIs, database relationships and transactions. Gradually, I became more comfortable understanding how the different components connect.

Based on the feedback I received on my capstone project, I would improve the system design documentation, particularly the architecture and database design. I would make the diagrams clearer and provide more detailed explanations of how the components communicate. I would also improve how I explain the flow of information between the frontend, API and database.

Next, I want to learn backend development in greater depth, especially building REST APIs, connecting applications to databases, authentication and implementing secure user operations. I also want to improve my JavaScript skills and gain more practical experience building complete applications. My goal is to move beyond designing systems on paper and become capable of developing functional applications that solve real-world problems.
